  совпали с таймаутами страниц `/api/v3/invoice` полного снимка с учётом UTC+3

  дашборда раз в час вместо каждых 10 минут: оценочно минус 19 240 вызовов за
  неделю, или 81,6% всего трафика. Далее: инкрементальный дневной снимок с полной
  ночной сверкой, исключение тяжёлых вложенных полей из списков, единый кэш
  коллекций и backoff/разведение тяжёлых обходов.
- Официальная документация API v1 указывает лимит 10 запросов/с на аккаунт,
  ETag/304 и `Limit`/`Offset`; API v3 описывает страницы по 100 и `pageAfter`.
  Отдельного официального лимита v3 и рекомендации по клиентскому таймауту в
  открытой документации не найдено. Наши 20/мин, 600/час и 3 секунды строже
