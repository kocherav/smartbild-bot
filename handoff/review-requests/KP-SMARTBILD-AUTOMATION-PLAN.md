# КП по автоматизации по шаблону SmartBild — план внедрения в бота

Поручение владельца 11.11: «КП, которые про автоматизацию, формировались по новому красивому
шаблону». Шаблон сделан в соседней сессии (`КП_SmartBild`: `build.cjs` → PDF, `build_docx.cjs` →
Word, `content.cjs` — тексты модулей, `assets/`; вход — JSON сделки). Публикация шаблона в
репозиторий запрошена веткой `handoff/KP-SMARTBILD-TEMPLATE`.

## Решения владельца (11.11)
1. **Выбор шаблона — сам по составу.** Бот определяет КП по автоматизации по позициям сделки
   (iRidi, контроллеры, шлюзы, Zigbee/KNX/DALI, DCM, датчики, панели, сервер умного дома…) и
   предлагает новый шаблон; в предпросмотре есть кнопка перейти на обычный КП (и обратно).
2. **Оформление — SmartBild, контакты владельца** (как в КП-906: Кочержинский А. В.,
   +7 (495) 846-72-71), без реквизитов юрлица.
3. **Модули — бот предлагает, владелец правит.** Модули (климат, свет, медиа, сценарии,
   уведомления…) подбираются по позициям; в предпросмотре — кнопки ✅/✖ по каждому модулю;
   PDF собирается только после подтверждения.

## Как встраивается
- Тот же маршрут, что сейчас: «📄 КП по сделке» / «сделай КП по сделке N» → адресат →
  предпросмотр → «✅ Создать PDF КП» → PDF в Telegram + вложение в сделку Мегаплана
  (`megaplan-crm/deal_proposal.py`: snapshot, fingerprint, проверка живой спецификации, без
  дублей). Меняется только оформление и добавляется выбор модулей.
- Данные: `deal_proposal.snapshot` уже даёт клиента, предмет, позиции с разделами
  «Оборудование и материалы» / «Работы и логистика», ставки НДС и итог — это вход шаблона
  (`number` = «КП-<сделка>», `date`, `client` = «адресат · клиент», `object` = предмет,
  `modules`, позиции по разделам, `vat`). Суммы — только из Мегаплана; итог шаблона
  сверяется с итогом сделки до копейки, иначе КП не формируется.
- Результат: PDF (в сделку и Telegram) + Word (в Telegram, для правок).
- Рендер — Node-скрипты шаблона, вызываемые из `deal_proposal.py` подпроцессом; зависимости
  ставит разработчик на сервере (npm, браузер для PDF, шрифты).
