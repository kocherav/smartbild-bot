# КП SmartBild — автоматизация (PDF и Word)

Коммерческое предложение по системам автоматизации дома в фирменном стиле SmartBild (брендбук v1.0).
КП собирается из двух входных файлов:
- **файл сделки** (JSON) — заказчик, объект, набор модулей, контакты, НДС;
- **таблица расчёта** (CSV) — оборудование и работы.

На выходе — PDF (A4 альбом) и/или Word (.docx, A4 альбом) с одинаковым составом страниц.

## Зависимости

| Что | Версия | Зачем |
|---|---|---|
| Node.js | ≥ 18 | сборщики |
| npm-пакет `playwright` | 1.56.1 (`package-lock.json`) | рендер HTML → PDF и картинок для Word через Chromium |
| Chromium для Playwright | — | `npx playwright install chromium` (на Linux-сервере, если нужно, ещё `npx playwright install-deps chromium`) |
| npm-пакет `docx` | 9.7.1 | сборка Word |
| Шрифт Inter | любой | PDF; без него Chromium подставит Arial. Debian/Ubuntu: `apt-get install fonts-inter` |

Word-версия использует Arial: так брендбук велит для офисных документов. Ставить его на сервер не нужно, шрифт подставит Word у клиента.

```bash
cd kp-smartbild
npm ci
npx playwright install chromium
```

## Сборка

```bash
node build.cjs      путь/к/сделке.json          # → КП_<имя>.pdf рядом с файлом сделки
node build.cjs      путь/к/сделке.json --png    # + картинки страниц КП_<имя>_01.png … (для проверки)
node build_docx.cjs путь/к/сделке.json          # → КП_<имя>.docx рядом с файлом сделки
```

- **`<имя>`** — поле `out` файла сделки, а если его нет — имя JSON-файла без расширения.
- **Word и картинки.** `build_docx.cjs` сначала сам вызывает `word_assets.cjs`. Тот рендерит HTML-версию этой сделки и снимает с неё экраны модулей и фон тёмных страниц в папку `_word_<имя>/` рядом с файлом сделки. Без аргумента `word_assets.cjs` обновляет общие картинки `assets/word/`: иконки, логотипы, экраны примера.
- **Время сборки:** около 2–5 с на PDF и 5–10 с на Word.
- **Ошибки:** при ошибке сборщик завершается с ненулевым кодом. При успехе в stdout печатается строка `ok: <путь> (N стр.: …)`.

Пример: `node build.cjs deals/КП-906/КП-906.json && node build_docx.cjs deals/КП-906/КП-906.json`.

## Файл сделки (JSON)

```json
{
  "number": "КП-906",
  "date": "11 ноября 2026",
  "client": "Сергей",
  "object": "Поставка и монтаж системы автоматизации",
  "modules": ["climate", "telegram", "scenes"],
  "table": "КП-906.csv",
  "vat": 5,
  "valid": "30 дней",
  "warranty": "по договору",
  "out": "КП-906",
  "manager": {
    "name": "Кочержинский Артем Вадимович",
    "role": "Руководитель проектов",
    "phone": "+7 (495) 846-72-71",
    "email": "info@smartbild.pro",
    "site": "smartbild.pro"
  },
  "overrides": { "climate": { "lead": "…", "pts": [["Жирное начало", "продолжение пункта"]] } }
}
```

| Поле | Обяз. | Что это | Где видно |
|---|---|---|---|
| `number` | да | номер КП (строка) | обложка: «№ … · дата»; название документа |
| `date` | да | дата строкой, как печатать | обложка |
| `client` | да | заказчик | обложка |
| `object` | да | объект / предмет предложения | обложка, страница расчёта |
| `modules` | да | список модулей, в нужном порядке (см. ниже); `[]` — без модулей | страницы модулей |
| `table` | нет | путь к CSV относительно файла сделки; нет поля — нет страницы расчёта | «Расчёт стоимости» |
| `vat` | нет | ставка НДС в %, НДС **включён** в цены; строка «В том числе НДС N %» под итогом | расчёт |
| `valid` | нет | срок действия; нет поля — фразы о сроке нет | расчёт |
| `warranty` | да | срок гарантии текстом («по договору», «2 года») | «Как мы работаем» |
| `out` | нет | имя результата (`КП_<out>.pdf/.docx`) | — |
| `manager.*` | да | `name`, `role`, `phone`, `email`, `site` | последняя страница |
| `overrides` | нет | свои тексты модулей под объект (см. ниже) | страницы модулей |

**НДС** считается по каждой строке с округлением до копеек и суммируется, как в счёте:
`Σ round(qty·price·vat/(100+vat), 2)`. Для КП-906: 39 973,91 ₽ при итоге 839 452,00 ₽.

### Модули (`modules`)

| Ключ | Страница | Скриншоты по умолчанию |
|---|---|---|
| `light` | Освещение и шторы | `living_light.jpg`, `tracks.jpg` |
| `climate` | Климат: отопление, кондиционеры, ПВУ, увлажнитель Breezart | `ventilation.jpg`, `humi.jpg` |
| `media` | Медиа и «Кино» | `kino.jpg`, `living_media.jpg` |
| `telegram` | Уведомления в Telegram и журнал | `journal.jpg` + телефон с чатом |
| `scenes` | Сценарии и фишки | `scenes.jpg` |

Страницы всегда в порядке: обложка → «Почему автоматизация» → модули из `modules` → «Как мы работаем» → расчёт (если есть `table`) → контакты.
Неизвестные ключи модулей пропускаются.

### Свои тексты модуля (`overrides`)

Поля поверх общих текстов из `content.cjs` (неуказанные остаются общими). Для `light`, `climate`, `media`, `telegram`:

| Поле | Тип | Что |
|---|---|---|
| `kicker` | строка | надзаголовок («Модуль · Климат») |
| `h` | строка | заголовок |
| `lead` | строка | вводный абзац |
| `pts` | `[[жирное, текст], …]` | пункты (лучше 5) |
| `ba` | `[было, стало]` | блок «Было → Стало»; `null` — без блока |
| `foot` | строка | строка «Совместимость: …»; `""` — без неё |
| `shots` | `[файл, файл]` | скриншоты из `assets/shots/`; у `telegram` — `[журнал]`, телефон с чатом рисуется сам |
| `chat` | `[[время, текст], …]` | только `telegram`: сообщения в телефоне |

Пример — `deals/КП-906/КП-906.json`: «Климат» про кондиционеры Daikin вместо ПВУ и Breezart.
Страницы «Почему автоматизация», «Сценарии», «Как мы работаем» и обложка меняются только в `content.cjs`.

## Таблица расчёта (CSV)

UTF-8 (BOM допускается), разделитель `;`, первая строка — заголовок:

```
Раздел;Наименование;Ед.;Кол-во;Цена
Оборудование и материалы;Iridi HS Server;шт.;1;93170
Работы и логистика;Монтажные работы;шт.;1;53000
```

- **Разделы:** группируются в порядке первого появления. Для каждого раздела считается «Итого: <раздел>», ниже — «Итого по предложению».
- **Числа:** `Кол-во` и `Цена` — числа, допускаются запятая и пробелы внутри цены. Цена — с НДС, если задан `vat`.
- **Нумерация** позиций сквозная.

## Файлы

| Файл | Что |
|---|---|
| `content.cjs` | все тексты КП (общие для PDF и Word), чтение CSV, формат рублей, расчёт НДС |
| `build.cjs` | сборка HTML → PDF (Playwright) |
| `kp.css` | стиль PDF по брендбуку: цвета, Inter, сетка A4 альбом |
| `build_docx.cjs` | сборка Word (`docx`) |
| `word_assets.cjs` | картинки для Word: экраны модулей, фоны, иконки и логотипы в PNG |
| `assets/brand`, `assets/icons` | логотипы и иконки из брендбука (SVG) |
| `assets/shots` | скриншоты интерфейса (логотип в шапке — SmartBild) |
| `assets/word` | готовые PNG для Word (общие) |
| `deal_example.json` + `table_example.csv` | пример со всеми модулями |
| `deals/КП-906/` | реальный пример: Daikin + iRidi, НДС 5 % |

## Ограничения

- В Word итоги таблицы — посчитанный текст, не формулы. При ручной правке цен в Word итоги пересчитываются вручную.
- Тексты модулей — продающие формулировки без числовых обещаний («экономия N %» сознательно не используется).
- Скриншоты — с реального объекта: на них план квартиры. Для публичных материалов их стоит заменить обезличенными.
