# Идеи тестировщика по улучшению бота

Тестировщик — не только поиск ошибок, но и изобретатель: предлагает, как сделать
работу менеджера короче и проще. Идеи — **предложения на решение владельца**, а не
дефекты: в работу они уходят заданием через `handoff/`, только после «берём».

Источники: ночной ИИ-судья (до трёх идей на миссию, вечерняя сводка «💡 Идеи
тестировщика») и наблюдения при прогонах стенда. Число нажатий измерено на стенде.

| № | Идея | Что мешает сейчас | Как сделать | Ценность | Решение |
|---|---|---|---|---|---|
| И-1 | **Быстрые действия в карточке сделки**: «📥 Счёт», «🧾 Выставить счёт», «🏢 Плательщик», «🔄 Статус» прямо под карточкой | Выставить общий счёт кнопками — 8 нажатий через 3 уровня меню (Сделки → Найти → По номеру → номер → Документы → Работа со счетами → Общий счёт → ✅); получить счёт — 6 | Inline-кнопки под карточкой открывают те же проверенные сценарии; вместе с И-2 путь до счёта — 4 действия (фразой «выстави счёт по сделке N» уже сейчас 3) | высокая | ждёт |
| И-2 | **Номер сделки без меню**: сообщение из одного 6-значного номера сразу открывает карточку | Перед вводом номера нужно 3 нажатия | Открывать карточку, только если нет активного вопроса бота или диалога ИИ за последние 10 минут (иначе номер может быть ответом на вопрос) | высокая | ждёт |
| И-3 | **Распознавание голосовых поручений** | Менеджеры в дороге диктуют; до 23.10 голосовое пропадало молча, теперь бот честно просит написать текстом | Расшифровка речи, затем тот же разбор фраз («смени плательщика…», «выстави счёт…»); любая запись — только через предпросмотр и кнопку | высокая | ждёт |
| И-4 | **Следующий шаг после записи**: после смены плательщика — «Выставить счёт новому плательщику?»; после счёта — «Отправить по ЭДО?» | Человек сам возвращается в меню и ищет следующее действие | Одна кнопка-предложение после подтверждённой записи; без автоматического выполнения | средняя | ждёт |
| И-5 | **Плательщики с ИНН и отметкой текущего** в списке выбора | В реальном снимке у клиентов 6–11 плательщиков; кнопки различаются только названием | Кнопка «ООО «Альфа» · ИНН …0001 · ✓ текущий»; поиск плательщика по ИНН во фразе | средняя | ждёт |
| И-6 | **Утренний список дел владельцу**: счета без оплаты дольше N дней, сделки без движения статуса | Должники и «зависшие» сделки видны, только если о них спросить | Ежедневное сообщение по данным счетов и банковского реестра (только чтение) | средняя | ждёт |
| И-7 | **Экономика без лишних записей** | Кнопка чтения трижды перезаписала файл в CRM | Взято владельцем 23.10 → `TASK-20261023-03` | высокая | в работе |
