# Идеи тестировщика по улучшению бота

Тестировщик — не только поиск ошибок, но и изобретатель: предлагает, как сделать
работу менеджера короче и проще. Идеи — **предложения на решение владельца**, а не
дефекты: в работу они уходят заданием через `handoff/`, только после «берём».

Источники: ночной ИИ-судья (до трёх идей на миссию) и наблюдения при прогонах стенда.

С 25.10 (решение владельца) каждая новая идея приходит после вечерней сводки отдельным
сообщением с кнопками «✅ Берём IDEA-…» / «🚫 Не надо IDEA-…»; нерешённые — «☰ Ещё → 💡 Идеи
тестировщика». Взятая идея сразу уходит разработчику по правилам `handoff/` (код только в
ветке `handoff/IDEA-…`, отчёт в `handoff/outbox/`, проверка по GitHub); отклонённая больше не
предлагается. По пятницам — обзор идей недели и их судьбы. Реестр решений —
`telegram-bridge/qa_ideas_state.json` на сервере (не в Git); тестировщик переносит итоги сюда. Число нажатий измерено на стенде.
