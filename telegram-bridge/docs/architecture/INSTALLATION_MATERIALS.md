# Материалы по счетам для монтажного кабинета

2026-10-03. Алгоритм и формат согласованы владельцем. По команде «Включай» включается выдача в кабинете монтажника.

## Рабочая выдача

«Мои монтажи» → объект → «📦 Материалы по счетам». Кнопка выдаёт PDF для телефона и полную Excel-книгу для компьютера. При передаче нового объекта уведомление сообщает о доступности этой кнопки. Старые уведомления повторно не рассылаются; уже переданные объекты получают кнопку при повторном открытии карточки. Массовая отправка файлов не производится.

Каждое нажатие пересобирает файлы из текущего локального учёта. `installer_material_delivery.py` сверяет Telegram-аккаунт с профилем и текущим назначением объекта до формирования; обработчик повторяет проверку перед отправкой. Доступны только transferred/in_progress/review; закрытые, чужие и неизвестные объекты отклоняются. Настроенный тестовый аккаунт сохраняет доступ к профилю Сергея. Черновик диалога не изменяется, файлы очищаются после отправки. Нет записей в финансовые реестры и запросов в CRM. Обновления не рассылаются автоматически: актуальная версия доступна по кнопке.

Реализация: `megaplan-crm/installation_materials.py`, тесты `test_installation_materials.py`.

## Утверждённое решение: Excel + PDF

Решение владельца от 03.10.2026: «Excel для компа и pdf для телефона».

- Для компьютера — полная Excel-книга: компактная сводка, подробные сопоставления и строки вне подтверждённых привязок; внутренние ссылки сохраняются.
- Для телефона и предпросмотра Telegram — PDF с утверждённой компактной таблицей на узких страницах, повторяемой шапкой и цветом в статусе. Не растягивать весь список на одну страницу и не возвращаться к длинным карточкам.
- Оба формата формируются за один запуск из одного набора данных, без цен. Распределения и экономика при экспорте не изменяются.
- Рекомендуемый вызов: `installation_materials.py DEAL_ID OUTPUT.xlsx --pdf OUTPUT.pdf` (без `--mobile-only`). Отдельная мобильная XLSX-книга — экспериментальный вариант, не стандарт выдачи.
- Формат принят; последующее разрешение «Включай» активирует кнопку и подсказку при передаче согласно разделу «Рабочая выдача». Исторические отметки ниже об отключённой выдаче относятся к этапу предпросмотра.

Ниже сохранена история проверок оформления; прежние гипотезы и запросы визуального подтверждения не отменяют это итоговое решение.

## Источники и ограничения

- Основа: локальный перечень закупаемых позиций сделки (`procurement_items`). Чистые работы исключены; закупаемые услуги сохранены.
- Подтверждение: сохранённые распределения счетов и подтверждённое использование остатков именно на эту сделку.
- Количество из `qty_used` — в единицах утверждённой привязки, не полное количество исходного счёта.
- Отсутствующие единицы исходного счёта не угадываем, показываем замечание.
- Прочая себестоимость и ещё доступные остатки связанных счетов видны отдельно. Остатки не закреплены за объектом.
- Названия, количества, единицы, номера счетов — разрешённые поля. Цены, суммы, реквизиты и исходные документы не экспортируются.
- Нет операций записи в CRM/реестры, повторной классификации расходов, подтверждения оплаты или поставки.

## Сопоставление

Утверждённые ID строк приоритетнее названий. Неоднозначный ID товара не заменяет ID строки.
Для неподтверждённых строк используется существующая оценка сходства названий; строго выше 0.5, до трёх кандидатов.
Это не вероятность правильности. Кандидаты не увеличивают покрытие. Различающиеся размеры/напряжения и несовместимые/неизвестные единицы отмечаются.

Жёлтый — возможная связь. Голубой — уже утверждённая связь с замечанием к исходным данным. Зелёный — полное подтверждённое покрытие без замечаний.
Автоматическое подтверждение кандидатов запрещено. Дальнейшее подтверждение — через существующий сценарий распределения счетов руководителем, не через изменение Excel.

## Выпуск

Проверка владельца опровергла гипотезу широких листов: Telegram iOS по-прежнему уменьшает отдельную XLSX-сводку, Excel iOS отображает её лучше. В мобильной книге скрыты E:XFD. Добавлен необязательный `--pdf` — фиксированная узкая страница 390×720 pt, поля 12 pt, текст 11 pt, повторяемая шапка таблицы. Для Telegram предназначен PDF, XLSX сохранён для Excel. Используются те же разрешённые поля сводки, без цен. Автовыдача монтажникам остаётся выключенной.

Проверка пустого поля в iPhone: добавлен CLI-флаг `--mobile-only`, сохраняющий сводку отдельной книгой без широких листов. Это проверка гипотезы о масштабе предпросмотра, а не подтверждённое исправление iOS. Внутренние ссылки удаляются, поскольку их цели остаются в полной версии. Полная версия и стандартный экспорт не изменены; потребуется визуальное подтверждение владельца.

Дополнение к компактному обзору: строки без кандидатов выше 50% показаны непосредственно на первом листе отдельным блоком «Есть в счетах — нет похожей позиции сделки». Полное сохранённое название источника не заменяется названием сделки и не сокращается; рядом количество соответствующей части и номер счёта. Прочая себестоимость и свободный остаток явно различаются, последний не обозначает закупку для объекта. Подробности доступны по внутренней ссылке. Исходные PDF повторно не распознаются: точность названий ограничена ранее сохранёнными данными.

Мобильное оформление, итерация 3: карточки отклонены владельцем как слишком длинные. Первый лист «Обзор для телефона» — четыре колонки: статус, материал, нужно, по счетам. Одна строка на позицию; цвет только у статуса, остальные ячейки с нейтральным чередованием. Требующие внимания идут первыми, покрытые последними. Название ссылается на строку второго листа «Сопоставления». Звёздочка у количества обозначает замечание к утверждённой привязке. Внизу ссылка на непривязанные строки. Кандидаты не меняют подтверждённые количества. Данные и правила покрытия не меняются. Отображение в конкретной версии мобильного Excel требует проверки владельцем.

На этом этапе доступен генератор и пример №894 только владельцу. Проверка примера завершена: формат принят. Кнопка монтажника, автоматическая выдача при передаче и уведомления НЕ включены. Файл генерируется заново из текущих локальных реестров; свежесть относительно CRM ограничена актуальностью локального учёта.

Проверки: изоляция сделки, частичное распределение, дубли, несовпадающие единицы, противоречащие характеристики, остатки, неизменность исходных данных, отсутствие финансовых значений и Excel-формул из внешнего текста.
