# Реестр шаблонов и формируемых файлов

Первичная инвентаризация. Точные файлы, ID шаблонов Мегаплана, версии и контрольные образцы устанавливаются на A1. Ниже не сертификат корректности документов.

| ID | Документ | Генератор / контур | Что проверить и зафиксировать |
|---|---|---|---|
| T-KP | КП КЛИВЭЛ | generate_kp.py / deal_proposal.py | Личный адресат, обложка и спецификация, различия двух путей, скидки и итог |
| T-CONTRACT | Договор Word и подписанный PDF | generate_contract.py / seller_documents.py | Наша организация, плательщик, подписант, преамбула, реквизиты, подпись/печать, шрифт |
| T-INVOICE | Клиентский счёт | contract_invoice.py / шаблоны Мегаплана | ID и название для каждой организации, основание с договором/датой, полный/этапный вариант |
| T-ECONOMY | Экономика план/факт | build_profitability_report.py | Скидки, единичная/строчная стоимость, валюта, источники факта, версии |
| T-MONTAGE | Монтажная ведомость | installation_workflow.py; старые генераторы отдельно | Одинаковый актуальный файл обеим ролям, полный утверждённый план, итоги отчётов, остатки |
| T-PROCUREMENT | Перечень оборудования и материалов | procurement_workflow.py | Поставщик, покрытие количества, цвет полностью закрытых строк |
| T-REGISTER | Бухгалтерский реестр | procurement_workflow.py | Поставщик, покупатель, счёт, сделка, стоимость, межфирменные строки |
| T-EDO | Письмо и Telegram-комплект | bridge.py | Тема клиент+плательщик, обращение Татьяне Григорьевне, номера/даты, наличие обеих вложений |

## Карточка шаблона

Версия; назначение; источник согласованного образца; путь/ID; организация; формат; обязательные поля и источники; правила имени файла; подписи и печати; правила скидок/НДС/валюты; пример без персональных данных; визуальная проверка; проверка сумм; место актуальной версии и архива; связанные сценарии; дата и результат приёмки.

Оригиналы договоров и счетов не заменять ради теста. Смена шаблона не должна незаметно менять уже выданный документ.
