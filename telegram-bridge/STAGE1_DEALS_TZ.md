# Этап 1. Работа со сделками

## Согласованный объём

- В главном меню есть отдельный раздел «Работа со сделками».
- Сделки можно вывести списком: последние 5, 10 или 15.
- Сделку можно найти по внутреннему номеру, клиенту или адресу объекта.
- Поиск по клиенту показывает до пяти последних подходящих сделок.
- После выбора сделка запоминается как текущая для данного Telegram-чата.
- Карточка показывает клиента, адрес, статус, исполнителя, сумму и число позиций.
- Для текущей сделки доступны связанные действия: экономика, позиции, учёт счёта и ведомость работ.
- Смена статуса показывает только переходы, которые Мегаплан разрешает из текущего статуса.
- Перед записью нового статуса бот обязательно запрашивает отдельное подтверждение.
- Непосредственно перед записью доступность перехода повторно проверяется в Мегаплане.

## Границы этапа

- Разбор отчётов монтажников и взаиморасчёты относятся к следующим этапам.
- Состав бригады не ведётся: один исполнитель соответствует одной бригаде.
- Монтажник в будущем видит весь объём работ в привязанной к нему сделке, но не общую экономику объекта.

## Приёмочная проверка

- Для чтения разрешено использовать сделку №887.
- В автоматической проверке запрещено менять статус №887.
- Реальный переход статуса выполняется только пользователем через кнопку подтверждения.
