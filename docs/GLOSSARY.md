# Глоссарий

| Термин | Значение |
|---|---|
| Сделка | Объект Мегаплана с клиентом, стадией, строками и документами |
| Суть сделки | Короткое человеческое название результата, не полный комментарий |
| Спецификация | Товары/работы с количеством, единицей, ценой и себестоимостью |
| КП | Коммерческое предложение клиенту |
| Плательщик | Лицо клиента в договоре и счёте |
| Продавец | Одна из собственных организаций SmartBild |
| Preview | Представление будущего изменения до записи |
| Квитанция | Доказательство завершения конкретного этапа |
| Read-back | Обратное чтение внешней системы после записи |
| Operation ID | Устойчивый ключ защиты от повтора |
| Реестр | JSON/SQLite-хранилище фактов и состояния |
| Проекция | Вычисленное представление, не источник истины |
| Worker | Фоновый обработчик долгой операции |
| Старая кнопка | Callback, созданный до смены контекста/версии |
| Неизвестный эффект | Тайм-аут, когда результат внешней записи неизвестен |
| Монтажная ведомость | Работы/количества для исполнителя без клиентской экономики |
| Накопительный отчёт | План/факт монтажа с прошлыми периодами |
| Нераспределённая закупка | Строка поставщика без сделки/позиции |
| Quality gate | Изолированный тест версии; не live-приёмка |
